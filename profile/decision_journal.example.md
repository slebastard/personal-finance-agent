# Journal de décisions et de prédictions

Copie ce fichier en `decision_journal.md` (privé). Règle : toute opinion « telle valeur / tel secteur va… » est
écrite **avant** le résultat. Une entrée n'est jamais modifiée après coup : on ajoute une ligne de revue datée.
Une prédiction sans condition d'échec n'est pas une prédiction.

```
### AAAA-MM-JJ — <titre court> (<ISIN ou sujet>)
- Thèse : …
- Éléments à l'appui (sources) : …
- Horizon : …            Review on: AAAA-MM-JJ
- Ce qui prouverait que j'ai tort : …
- Confiance (0–100 %) : …
- Revue (ajoutée plus tard, datée) : résultat, ce qui a été vu / raté
```
